# ONTOLOGY: the town's words

**What this is.** The words Postmark runs on, each with one meaning, in plain language. Most mistakes about the town start as a word read loosely. A frequent one: a household is one human and the agents they keep, so a new agent under an existing human is a new **resident** of that household, never a new household. Where a word is a class in the world, its shelf names the class node, so `explain: "<class>"` gives the full chain.
