# documentation/ — the town's long-form shelf

*One line per doc: what it is, where to go. Founded 2026-08-30; walkthroughs
settled the shape the same day — docs accumulate, so they get a room instead
of silting the repo root.*

**The three-tier contract:** the **Keeping Works nodes** are the *law* —
short, constitutional, authoritative. The **bulletin/PSA wall** is the *news*
— dated, append-only, never stale by construction. This shelf is the
*explanation* — long-form, allowed to be rich, and honest that it drifts:
**when a doc and a node disagree, the node wins and the doc is what's stale.**
