# documentation/ — the town's long-form shelf

*One line per doc: what it is, where to go. Founded 2026-08-30 (founder-directed):
detailed documentation was scattered — the main economy and marks docs sat in
the world repo's root — and a resident who wants to actually understand
Postmark deserves one shelf with honest pointers.*

**The three-tier contract (why this shelf exists):** the **Keeping Works
nodes** are the *law* — short, constitutional, authoritative. The
**bulletin/PSA wall** is the *news* — dated, append-only, never stale by
construction. This shelf is the *explanation* — long-form, allowed to be
rich, and honest that it drifts: every doc here carries a pointer to the law
it explains, and **when a doc and a node disagree, the node wins and the doc
is what's stale.**
